# hangul-wrap — 한글 어절 지키기

브라우저는 한글을 글자 사이 어디서나 꺾습니다. 손대지 않은 한국어 화면은 "프로젝 / 트" 처럼 어절이 쪼개집니다. 반대로 `keep-all` 을 아무 데나 주면 긴 명령어·URL 이 칸을 뚫고 나갑니다. 그래서 **재고 → 자리별로 고치고 → 다시 잽니다.**

## 1. 재기 (고치기 전)

1. 대상 페이지를 연다 (로컬 dev 서버 주소나 HTML 파일). 없으면 주소 하나만 묻는다
2. 폭 6개에서 같은 페이지를 잰다: **320 · 360 · 390 · 768 · 1024 · 1440**
3. 폭마다 이 스킬 폴더의 `wrapcheck.js` 내용을 페이지 안에서 실행한다
   - 브라우저 자동화 도구(Claude in Chrome, 내장 브라우저)의 JS 실행, 또는 Playwright `page.evaluate`
   - 브라우저를 쓸 수 없으면 처방은 "제안" 으로만 내고 결과 맨 위에 **"실측 안 함"** 이라고 적는다
4. 결과를 표로 남긴다

| 폭  | 어절 쪼개짐 | 고아 줄 | 넘친 요소 | 페이지 가로 넘침(px) |
| --- | ----------- | ------- | --------- | -------------------- |

## 2. 고치기 — 자리별 처방

일괄 규칙 하나로 끝내지 않는다. 쪼개진 자리가 어떤 역할인지 보고 고른다.

| 자리                     | 처방                                                                          |
| ------------------------ | ----------------------------------------------------------------------------- |
| 전체 기본값              | `word-break: keep-all; overflow-wrap: break-word;` (body 또는 :root)          |
| 제목                     | `text-wrap: balance;` — 줄 길이를 고르게, 한 단어만 떨어지는 줄 방지          |
| 본문 문단                | `text-wrap: pretty;` — 마지막 줄 고아 방지                                    |
| 코드·URL·긴 명령어       | `overflow-wrap: anywhere;` — 이 자리만 아무 데서나 꺾이게 허용                |
| 좁은 grid·flex 칸        | grid 는 `minmax(0, 1fr)`, flex 자식은 `min-width: 0` — 긴 글이 칸을 밀지 않게 |
| 꼭 붙어야 하는 짧은 묶음 | `white-space: nowrap;` 을 그 span 에만 (예: "3월 15일", 금액+단위)            |

**금지**

- `word-break: break-all` — 어절을 아무 데서나 자른다. 기존 코드에 있으면 위 표의 해당 자리 처방으로 바꾼다
- `<br>` 로 줄 맞추기 — 한 폭에서만 맞고 다른 폭에서 깨진다
- 고치라고 한 화면 밖까지 손대기 — 같은 문제가 다른 곳에 보이면 목록으로 알리고 묻는다

## 3. 다시 재기

1단계와 같은 폭 6개에서 다시 잰다. 결과는 전·후를 나란히 보고한다.

```markdown
| 폭 | 쪼개짐 전→후 | 고아 전→후 | 넘침 전→후 |
```

- 0이 아닌 곳이 남으면 그 어절·요소와 이유를 적는다 (예: 태그를 걸친 어절이라 검사기가 못 봄, 의도한 nowrap)
- 프로젝트에 디자인 규칙 문서(`DESIGN.md` 등)가 있으면 적용한 처방을 한 줄로 기록하자고 제안한다

## 검사기 한계

- 한 텍스트 노드 안의 어절만 본다. `<b>한</b>글` 처럼 태그를 걸친 어절은 눈으로 확인한다
- 글자 크기를 키운 상태·브라우저 확대(150·200%)는 재지 않는다. 접근성까지 볼 땐 확대 상태에서 한 번 더 돌린다
- 더 정밀한 실측(글리프 위치로 줄 재구성, 확대 상태 버튼 잘림)이 필요하면 [hanmariyang/giting-skills 의 hangul-wrap](https://github.com/hanmariyang/giting-skills/tree/main/plugins/hangul-wrap) 을 쓴다
