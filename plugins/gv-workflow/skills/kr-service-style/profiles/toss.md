# 프로필: 토스식 (`toss`)

모든 항목은 공식 출처에서 확인한 것을 우리 말로 다시 쓴 것이다. `[A1]` 같은 표시는 맨 아래 출처 번호다. 출처에 없는 값은 지어내지 않고 "미확인" 으로 둔다.

범위마다 **기존 시안에서 찾을 것 → 바꾸는 법** 으로 적었다. 고른 범위의 표만 적용한다.

## 철학 — 판단 기준 (직접 적용하지 않음)

규칙이 애매하거나 서로 부딪힐 때 이 순서로 판단한다.

1. **단순함**: 있으면 좋은 것보다 없으면 안 되는 것만 [T1]
2. **사용자 부담 줄이기**: 생각할 것·입력할 것·기다릴 것을 줄이고, 절차는 뒤로 [T2]
3. **존중**: 비용을 숨기지 않고 혜택을 부풀리지 않는다. 강요·겁주기 대신 권한다 [T3]

## 문구 — UX 라이팅

가치: 명확하게 · 간결하게 · 친근하게 · 존중하며 · 공감하며 [T3]

| 규칙                  | 기존 시안에서 찾을 것                     | 바꾸는 법                                                                              | 출처   |
| --------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------- | ------ |
| 해요체로 통일         | "~습니다", "~입니다" 가 섞인 문구         | 모두 해요체. 합니다체를 섞지 않는다                                                    | A1     |
| 능동형                | "완료됐어요", "처리되었습니다"            | "완료했어요", "처리했어요"                                                             | A1     |
| 긍정형                | "안 돼요", "할 수 없습니다"               | "~하면 할 수 있어요". 정책상 불가하거나 안심시킬 때만 부정형, 이유를 붙인다            | A1     |
| 과한 경어 금지        | "~시겠어요", "~께", "계시다"              | "~할까요?", "~에게", "있다"                                                            | A1     |
| 되어요 → 돼요         | "되어요", "되었어요"                      | "돼요", "됐어요"                                                                       | A1     |
| 명사 나열 금지        | "본인 인증 진행 필요"                     | 동사로 푼다: "본인 인증을 해 주세요"                                                   | A1     |
| 메시지 하나           | 한 문장에 정보 둘 이상, 같은 말 되풀이    | 한 문장에 메시지 하나. 빼도 뜻이 같은 단어는 지운다. 소리 내 읽어 확인                 | T3     |
| 다음 일을 미리 알리기 | 누르면 무슨 일이 생길지 안 적힌 버튼·안내 | 다음 화면에서 생길 일을 적는다                                                         | T3     |
| 쉬운 말               | 업계 용어 (예: "이체 한도", "인증서")     | 일상어로                                                                               | T2     |
| 유행어 금지           | 유행어·은어·밈                            | 평범한 말로                                                                            | T3     |
| 보조 버튼 "닫기"      | 창을 닫기만 하는 "취소" 버튼              | "닫기" ("취소" 는 작업 취소로 오해된다). 정말 작업을 취소하면 "취소" 유지              | A1     |
| 버튼 이름             | —                                         | 버튼 하나면 "~하기", 다음 화면으로 넘기면 "확인"·"다음", 둘이면 보조는 "닫기"·"다음에" | A1, T4 |
| 바텀시트 제목         | 두 줄 이상 제목                           | 한 줄                                                                                  | A1     |
| 숫자·금액 표기        | —                                         | **미확인**                                                                             |        |

## 가져오지 않는 것

- 토스 프로덕트 산스(전용 서체, 공개 라이선스 없음) → Pretendard 등 OFL 서체로
- TDS Figma 키트, 토스 그래픽·3D·아이콘: 앱인토스 밖 사용·복제·수정 금지 [A2][A1]
- 토스 파랑 `#3182F6` 을 주색으로: 문서상 금지 조항은 아니지만 토스로 오인될 수 있어 사용자 브랜드 색으로 바꾼다 (판단)
- 토스페이스(이모지): 쓰려면 사용자가 공식 페이지에서 받아 출처를 표시한다. 변형 금지
