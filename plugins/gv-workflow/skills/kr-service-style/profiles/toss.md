# 프로필: 토스식 (`toss`)

모든 항목은 공식 출처에서 확인한 것을 우리 말로 다시 쓴 것이다. `[A1]` 같은 표시는 맨 아래 출처 번호다. 출처에 없는 값은 지어내지 않고 "미확인" 으로 둔다.

## 원칙

1. **한 화면에 할 일 하나.** 주 행동 버튼도 하나 [T1][T2]
2. **꼭 필요한 기능만.** 있으면 좋은 것보다 없으면 안 되는 것 [T1]
3. **첫 화면은 입력 하나.** 나머지는 다음 단계로 넘긴다 (예: 금액 먼저, 받는 사람은 다음) [T2]
4. **경고는 실수했을 때만.** 미리 경고 문구를 깔지 않는다. 틀렸을 때 이유와 다시 하는 법을 알린다 [T2]
5. **절차는 뒤로.** 안전에 꼭 필요하지 않은 인증·입력은 없애고, 필요한 인증은 최대한 늦게 [T2]
6. **쉬운 말.** 업계 용어는 일상어로 바꾼다 [T2]
7. **다크패턴 금지.** 들어오자마자 뜨는 시트, 나가려 할 때 붙잡는 시트, 거절할 수 없는 선택, 갑작스러운 전면 광고, 결과를 알 수 없는 버튼 [A1]

## 문구

- 가치: 명확하게 · 간결하게 · 친근하게 · 존중하며(비용 숨기지 않기, 혜택 부풀리지 않기) · 공감하며 [T3]
- 쓰는 법 [T3]
  - 다음 화면에서 무슨 일이 생길지 미리 알려 준다
  - 빼도 뜻이 같은 단어, 같은 말을 되풀이하는 문장은 지운다
  - 핵심 메시지 하나만 남긴다. 한 문장에 메시지 하나, 소리 내 읽어도 자연스럽게
  - 강요하거나 겁주지 않고 권한다
  - 유행어·은어·밈을 쓰지 않는다
  - 정보 뒤에 있는 감정을 헤아린다
- 문장 규칙 [A1]
  - **모든 문구 해요체.** 합니다체를 섞지 않는다
  - **능동형** ("완료됐어요" → "완료했어요"), **긍정형** ("안 돼요" → "~하면 할 수 있어요"). 정책상 불가하거나 안심시켜야 할 때만 예외, 부정형엔 이유를 붙인다
  - **과한 경어 금지**: "~시겠어요", "~께", "계시다"
  - 명사를 이어 붙이지 말고 동사로 푼다
  - "되어요" → "돼요"
- 버튼 [A1][T4]
  - 다이얼로그 보조 버튼은 **"닫기"** ("취소"는 작업 취소로 오해된다)
  - 버튼 하나면 "~하기", 다음 화면으로 넘기면 "확인"·"다음", 둘이면 보조는 "닫기"·"다음에"
  - 바텀시트 제목은 한 줄
- 숫자·금액 표기 규칙: 미확인

## 화면 패턴

- **글자 크기 단계** (크기/행간 px) [D1]: 30/40 · 26/35 · 22/31 · 20/29 · **17/25.5 (본문)** · 15/22.5 · 13/19.5 (덜 중요한 글). 최소 11px. 값을 직접 박지 말고 토큰·상대 단위로 써서 시스템 글자 확대를 따라가게 한다
- **색 구조** [D2][D3]: 색마다 50~900 단계. 배경은 흰색. 주 행동은 진한 채움, 보조 행동은 같은 색의 연한 바탕(weak). **색 값은 사용자 브랜드 색으로 바꿔 끼운다**
- **리스트** [D4]: 왼쪽(아이콘) · 가운데(글) · 오른쪽(부가 정보·행동). 상하 여백 8/12/16/24px(기본 12), 좌우 20/24px(기본 24). 누를 수 있는 줄엔 화살표와 눌림 효과. 로딩은 실제 모양의 스켈레톤
- **하단 고정 CTA** [D5]: 기본 버튼 하나, 필요할 때만 둘
- **그래픽** [A1]: 화면당 핵심 그래픽 하나, 아이콘 24~40px 한 번에 하나, 파티클·과한 그라데이션 금지, 오류가 아닌데 느낌표 금지, 글·버튼보다 튀지 않게
- **탭**: 2~5개 [A1]
- 전역 간격·모서리 둥글기 수치: 미확인 (공개 문서에 없음)

## 가져오지 않는 것

- 토스 프로덕트 산스(전용 서체, 공개 라이선스 없음) → Pretendard 등 OFL 서체로
- TDS Figma 키트, 토스 그래픽·3D·아이콘: 앱인토스 밖 사용·복제·수정 금지 [A2][A1]
- 토스 파랑 `#3182F6` 을 주색으로: 문서상 금지 조항은 아니지만 토스로 오인될 수 있어 사용자 브랜드 색으로 바꾼다 (판단)
- 토스페이스(이모지): 쓰려면 사용자가 공식 페이지에서 받아 출처를 표시한다. 변형 금지
