# 프로필: 당근식 (`karrot`)

근거는 당근 디자인 시스템 SEED(Apache-2.0)의 공개 문서와 당근 공식 블로그다. 우리 말로 다시 썼다. 출처에 없는 값은 "미확인".

범위마다 **기존 시안에서 찾을 것 → 바꾸는 법** 으로 적었다. 고른 범위의 표만 적용한다.

## 철학 — 판단 기준 (직접 적용하지 않음)

- 프로덕트 디자인 원칙 7개 [C1]: 연결된 경험 · 사용자를 위한 개선 · 직관적인 경험 · 하나의 화면 하나의 목표 · 단순한 시각 요소 · 적절한 피드백 · 간결한 문구. **항목명만 공개, 설명은 비공개** → 이름 이상으로 해석해 규칙을 만들지 않는다
- 말하기 톤 "활기차고 친절하게" [S1]: 명확하게(결정에 필요한 정보만) · 쉽게(누구나 이해하게) · 사려 깊게(다양성 존중, 글에 감정이 실린다는 걸 의식)

## UX — 사용 흐름·화면 구조

| 규칙                    | 기존 시안에서 찾을 것                        | 바꾸는 법                                             | 출처 |
| ----------------------- | -------------------------------------------- | ----------------------------------------------------- | ---- |
| 하나의 화면 하나의 목표 | 한 화면에 목적이 둘 이상, 채운 버튼 2개 이상 | 목표 하나만 남기고 나머지는 다음 화면·보조 버튼으로   | C1   |
| 그 밖의 흐름 규칙       | —                                            | **미확인** (원칙 설명 비공개). 토스 UX 를 섞지 않는다 |      |

## UI — 화면 모양

| 규칙           | 기존 시안에서 찾을 것                | 바꾸는 법                                                                                              | 출처   |
| -------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------ | ------ |
| 간격           | 제각각인 여백, 홀수 px               | 2px 단위 토큰 2~64px. 화면 좌우 여백 16px, 칩 사이 8px, 화면 하단 56px                                 | S3     |
| 모서리         | 요소마다 다른 둥글기                 | 2~24px 단계 + 완전 둥글게(9999px). 버튼 완전 둥글게, 카드 r3(12px 단계), 입력창 r2(8px 단계)           | S4, K1 |
| 글자 단계      | 한 화면 글자 크기 5단계 이상         | 11~48px 14단계 안에서, **한 화면 4단계 이내**. iOS·Android·macOS 는 시스템 서체, Windows 는 Pretendard | S5, K1 |
| 카드 안쪽 여백 | 16px 미만                            | 최소 16px (x4)                                                                                         | K1     |
| 색             | 색 값을 직접 박음 (`#ff6600`, `red`) | 역할 이름 토큰(fg.brand, bg.neutral 등)으로. 브랜드 색 자리에 **사용자 브랜드 색**                     | S6, K1 |

## 문구 — UX 라이팅

| 규칙                       | 기존 시안에서 찾을 것                 | 바꾸는 법                                   | 출처 |
| -------------------------- | ------------------------------------- | ------------------------------------------- | ---- |
| 해요체 ("~니다" 는 경고만) | 자동 경고가 아닌데 "~습니다"          | 해요체. "~니다" 는 자동으로 나가는 경고에만 | S2   |
| 익숙한 말                  | 한자어 ("불가능합니다")               | 풀어 쓴다 ("할 수 없어요")                  | S2   |
| 존칭 줄이기                | "찾고 계신가요"                       | "찾고 있나요"                               | S2   |
| 숫자                       | "세 개", "삼일"                       | 아라비아 숫자 ("3개", "3일")                | S2   |
| 줄임말·은어 금지           | "ㄱㄱ", "득템"                        | 평범한 말로                                 | S2   |
| 목적을 말하기              | 기능 이름만 적힌 안내 ("알림 설정")   | 하려는 일을 적는다 ("새 글 알림 받기")      | S2   |
| 긍정·능동                  | 부정문·피동문                         | 같은 뜻이면 긍정문, 기본은 능동문           | S2   |
| 사용자 행동으로            | "데이터가 삭제되었습니다"             | "글을 지웠어요"                             | S2   |
| 한 문장에 목적 하나        | 목적 둘 이상인 문장                   | 나눈다                                      | S2   |
| 느낌표 아끼기              | 느낌표 여러 개                        | 꼭 필요한 한 곳만                           | S2   |
| 상태값 붙여 쓰기           | "예약 중"                             | "예약중"                                    | S2   |
| 마침표                     | 버튼·라벨·20pt 이상 큰 글씨 끝 마침표 | 뺀다. 마침표는 평서문에만                   | S2   |
| CTA                        | 13자 이상, 명사로 시작                | 동사로 시작, 12자 이내                      | K1   |

## 가져오지 않는 것

- 당근 로고·이름 (Apache-2.0 은 상표권을 주지 않는다) [C2]
- 당근 주황(`#FF6600`, 웹 실측 `#FF6F0F`)을 주색으로 (판단)
- 아이콘 패키지 `@karrotmarket/icon`: 라이선스 미확인 → 쓰지 않는다
- 캐릭터: 정책 미확인 → 쓰지 않는다
