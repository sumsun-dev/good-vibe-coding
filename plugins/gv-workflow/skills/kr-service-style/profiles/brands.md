# 네이버 · 카카오 · 배민 — 쓸 수 있는 것과 경계

세 회사는 디자인 원칙이나 UX 라이팅 가이드를 공개 문서로 거의 내지 않았다 (2026-11-04 조사). 그래서 "OO식 화면" 프로필은 만들지 않는다. 스타일을 요청받으면 이 사실을 알리고, 아래의 **공개 서체 + 공개된 원칙 + 경계** 와 `toss`·`karrot` 프로필의 공통 원칙으로 진행한다. 출처 없이 "네이버라면 이럴 것" 을 지어내지 않는다.

## 네이버

- 공개된 원칙
  - 다크패턴 방지 4원칙 [N1]: 판단은 사용자가 직접 하게 · 일부러 포기하게 만들지 않기 · 치우치지 않은 완전한 정보 · 압박하지 않기. 문구에서는 부정 표현을 피하고 정확한 말을 쓴다
  - 정보가 많은 화면에서 모호함·시각 피로·두려움·작업 단계를 줄인다 [N2]
- 서체: 나눔고딕·나눔명조·나눔스퀘어(라운드·네오)·나눔바른고딕·나눔손글씨·마루 부리 등. **SIL OFL 1.1** — 상업적 사용·수정·재배포 가능, 서체 파일 자체 판매만 금지. 라이선스 전문을 넣기 어려우면 출처 표기 [N3]
- 경계 [N4]: 로고·N 심볼 변형·재사용 금지, 네이버와 관계있는 것처럼 오인시키는 사용 금지, 브랜드 자산을 템플릿·데이터셋·생성형 AI 학습자료로 재배포 금지. 그린 `#03C75A` 는 핵심 브랜드 자산 → 주색으로 쓰지 않는다
- 네이버 로그인 버튼은 **가이드대로** [N5]: 지정 녹색(`#03A94D`) 변경 불가, N 로고 아이콘형 18px·완성형 16px 이상, 가운데 정렬 시 로고-글자 간격 8px, 왼쪽 정렬 시 로고 왼쪽 여백 20px, 글자는 로고보다 작게, 다른 소셜 버튼보다 작게 줄이지 않기. 문구는 목적에 맞으면 바꿀 수 있다 ("네이버로 로그인", "네이버로 간편가입")

## 카카오

- 공개된 디자인 원칙·UX 라이팅: 찾지 못함
- 서체: **카카오 글씨** — 큰글씨(제목용)·작은글씨(본문·캡션용) 각 3굵기, **OFL**, 개인·상업 무료 [K1]
- 경계 [K2]: 카카오 상표 변형·결합 금지, 내 앱 이름·아이콘·로고에 카카오 상표 금지, "for Kakao" 처럼 카카오 서비스로 오인시키는 표현 금지. 카카오 노랑(`#FEE500`, 카카오뱅크 `#FFE300`)으로 일반 화면을 칠하지 않는다 (오인 유도 조항에 근거한 판단). 캐릭터: 규정 미확인 → 쓰지 않는다
- 카카오 로그인 버튼은 **가이드대로** [K3]: 배경 `#FEE500`, 심볼·글자 검정(글자 85%), 모서리 12px, OS 기본 서체, 말풍선 심볼 필수·변형 금지, 문구 "카카오 로그인"(축약 "로그인"). 작아야 하면 비율을 줄이지 말고 축약형. 다른 로그인 버튼보다 덜 보이게 만들지 않는다. 카카오싱크는 "카카오로 시작하기"

## 배달의민족

- 공개된 원칙: "쉽고 빠르고 위트있게" [B1]. 디자인 시스템은 "이 기능은 항상 이렇게 동작한다" 식의 규칙 중심, 정보는 카드 조합, 조회 UI 와 편집 UI 를 나눈다 [B2]
- 문구: 시작 전에 걸리는 시간을 알려 준다 ("2분이면 끝나요" — 실제로 재서 정한 시간), 선택한 사람보다 남은 인원을 보여 준다 [B3]
- 서체: 한나·주아·도현·연성·기랑해랑·을지로 등. **SIL OFL 1.1** — 영리 사용·수정 가능, 앱 UI·로고 용도 명시. 서체 파일 판매 금지, **고친 서체는 원래 이름을 쓸 수 없다**, 다른 소프트웨어와 묶어 배포하면 라이선스 전문 포함 [B4]
  - 배민도 서비스 본문엔 자기 서체를 쓰지 않는다 (개성이 강하고 굵기가 적어서) → **제목·포인트에만** [B5]
- 경계: 로고·배달이친구들 캐릭터·브랜드색. 공식 금지 문구는 미확인, 브랜드 민트 공식 값도 미확인 → 비슷한 민트를 주색으로 쓰지 않는다
